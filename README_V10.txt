ESTIM'IA V10 — ADRESSE / CADASTRE / SURFACES

Nouveautés :
- propriétaire + téléphone dans le dossier ;
- extraction du propriétaire depuis la dictée ;
- extraction d'une adresse dictée ;
- vérification/normalisation de l'adresse avec le service public IGN/BAN ;
- propositions d'adresses : l'agent choisit, aucune ambiguïté n'est validée silencieusement ;
- recherche cadastrale par commune/code INSEE + section + parcelle ;
- conservation des références cadastrales au dossier ;
- surfaces détaillées par pièce ;
- affectation par niveau : sous-sol, rez-de-jardin, RDC, 1er, 2e, 3e, combles ;
- sous-total automatique pour chaque niveau ;
- total intérieur renseigné ;
- annexes et extérieurs séparés et exclus du total intérieur ;
- comparaison avec la surface habitable/Carrez annoncée ;
- mise en page visible et imprimable.

Important :
- un total de pièces dictées n'est pas présenté comme une surface Carrez certifiée ;
- une adresse proposée doit être validée par l'agent ;
- une association adresse/parcelle issue d'un référentiel public reste à confirmer ;
- microphone V9 inchangé ;
- aucun service OpenAI payant ajouté.
