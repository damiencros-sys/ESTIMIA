FIBRE : accès direct au site fourni par l’utilisateur https://numerique.herault.fr/1595-testez-votre-eligibilite.htm. Recherche dans le jeu IPE actuellement utilisé par sa carte : ipe-deploiement-fibre-optique-par-immeuble, champs communeimmeuble et identifiantimmeuble. Une adresse avec suffixe ou plusieurs bâtiments doit être confirmée ; aucun statut attribué au hasard. Panne, absence de réponse ou absence d’adresse = non vérifié, jamais inéligible par défaut. Raccordement déclaré et éligibilité publiée distincts. Source, date et bâtiment repris dans Word/PDF. Le bouton vers le site officiel reste disponible si le service de données est lent ou indisponible.

Importer le fichier ANALYSE_PHOTOS_TRAIZIT.json fourni séparément dans le dossier TRAIZIT. Les constats non acceptés n’alimentent pas le document client. Seule une proposition d’état acceptée agit sur la correction d’état ; les budgets restent prioritaires. Ajouter des photos seul ne les analyse pas. Aucune analyse automatique d’images intégrée.

COMPLÉTER LA VISITE : rubrique repliée par défaut, 25 choix regroupés (atouts, disposition, équipements, travaux et vérifications, état général). Boutons Appartement/Studio pour cibler le logement. Choix explicites de la dictée reconnus quand leur logement est identifiable ; aucun rattachement arbitraire d’un adjectif ambigu. Boutons sélectionnés colorés, retrait et ascenseur avec/sans exclusifs. Travaux sans prix inventé ; toiture à vérifier = vigilance, pas travaux affirmés. Les ajouts et retraits restent enregistrés dans le dossier ; le texte source de la dictée est conservé. Les caractéristiques et travaux restent modifiables dans leurs rubriques.
