ESTIM'IA V12 — correctif ciblé

- Le mot "étage" seul déclenche désormais immédiatement le passage au 1er étage.
- RDC, étage, 2e étage, 3e étage, sous-sol, rez-de-jardin et combles sont des états persistants : les pièces suivantes restent à ce niveau jusqu'au prochain changement.
- Réseaux : plus aucun texte libre parasite. Seulement électricité, gaz, eau, assainissement, fibre.
- Fibre non connectée/non raccordée conserve explicitement la négation.
- Annexes : plus de "Détail 1/2/3". Garage avec mezzanine devient un attribut du garage.
- Moustiquaires localisées au RDC lorsque la dictée le précise.
- Propriétaire : "les consorts Fumat" devient "Consorts Fumat"; "famille Fumat" est conservé.
- Commune dictée normalisée via le service public avant recherche cadastrale.
- Recherche cadastrale : code INSEE + section + numéro selon les paramètres officiels API Carto IGN.
- Surface intérieure calculée affichée très visiblement, sans la faire passer pour une Carrez certifiée.
- Micro inchangé.
